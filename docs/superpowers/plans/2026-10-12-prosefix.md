## Spec amendments (found while planning; Task 0 records them in the spec)

1. **Changes are derived, not collected.** stylefix's `normalize()` rewrites quotes, dashes, ranges and apostrophes without recording edits, and proofix rewrites its text in several passes whose edit records refer to intermediate texts. So each pass's `Result.changes` is computed by diffing its input and output (lines, then tokens within changed lines); the pass's edit records and decisions only *label* the hunks (check, reason, decided_by, confidence). Faithfulness then holds by construction. A hunk no record matches gets the pass's default label (`punctuation` for stylefix, `proofix` for proofix) and `decided_by: "rule"`.
2. **`depends_on` means "supersedes".** A change listing `depends_on` already contains the full effect of the changes it lists over its span. Applying a selection: drop every change a selected change depends on, then splice the rest in descending `(start, end)` order. Valid selections are those closed under `depends_on` (selecting a change selects its dependencies).
3. **Two cache files.** proofix's comma decisions keep their own cache format, so a project has `.prosefix/cache.json` and `.prosefix/commas.json`; the `cache` setting names the first and the second sits beside it.
4. **`replay_cache`.** With no endpoint, stylefix sends style items straight to review and proofix skips compounds, so a cache could not be replayed. Both `Options` gain `replay_cache: bool = False`: with no endpoint, build every adjudication item as if a model were present and answer it from the cache only. prosefix sets it for `--llm cached`. CLIs leave it off (behaviour unchanged).
5. **Vale runs on a temporary file** inside `stylefix.api.fix` (Vale reads files); "no file I/O" means none on the caller's files.
6. **proofix's LanguageTool replay fixture** in `tests/test_e2e.py` patches `proofix.api` instead of `proofix.cli` (two lines), because the calls move. This is the one permitted edit to an existing test.

```python
def _mutate(rng, text):
    words = text.split(" ")
    for _ in range(rng.randint(0, 6)):
        i = rng.randrange(len(words))
        op = rng.choice(["swap", "del", "ins", "punct"])
        if op == "swap":
            words[i] = words[i][::-1]
        elif op == "del" and len(words) > 1:
            words.pop(i)
        elif op == "ins":
            words.insert(i, rng.choice(["new", "x,", "“q”", "\U0001F600"]))
        else:
            words[i] += rng.choice([",", ";", "—"])
    return " ".join(words)
```

```python
"""Changes between texts as labelled, non-overlapping splices.

A pass's changes are derived from a diff of its input and output (lines, then
tokens inside changed lines), so applying them always reproduces the output;
the pass's own records only label the hunks. compose() re-expresses a second
pass's changes against the first pass's input, merging any that overlap a
first-pass change into one change that depends on (and supersedes) it."""

from __future__ import annotations

import difflib
import re
from dataclasses import dataclass, field

_TOKEN = re.compile(r"\w+|\s+|[^\w\s]")


@dataclass
class Change:
    start: int
    end: int
    before: str
    after: str
    check: str = ""
    reason: str = ""
    decided_by: str = "rule"          # rule | model | cache
    confidence: float = 1.0
    id: str = ""
    pass_: str = ""
    depends_on: tuple[str, ...] = ()


@dataclass(frozen=True)
class Annotation:
    before: str
    after: str
    check: str
    reason: str = ""
    decided_by: str = "rule"
    confidence: float = 1.0


@dataclass(frozen=True)
class ReviewItem:
    line: int
    kind: str                          # undecided | rejected | alert | note
    message: str
    check: str = ""
    pass_: str = ""


@dataclass(frozen=True)
class Skipped:
    what: str
    why: str
    fix: str


def _starts(parts: list[str]) -> list[int]:
    out = [0]
    for p in parts:
        out.append(out[-1] + len(p))
    return out


def _token_hunks(a: str, b: str, base: int):
    ta, tb = _TOKEN.findall(a), _TOKEN.findall(b)
    oa, ob = _starts(ta), _starts(tb)
    for tag, i1, i2, j1, j2 in difflib.SequenceMatcher(None, ta, tb, autojunk=False).get_opcodes():
        if tag != "equal":
            yield base + oa[i1], base + oa[i2], b[ob[j1]:ob[j2]]


def _hunks(before: str, after: str):
    la, lb = before.splitlines(keepends=True), after.splitlines(keepends=True)
    pa, pb = _starts(la), _starts(lb)
    for tag, i1, i2, j1, j2 in difflib.SequenceMatcher(None, la, lb, autojunk=False).get_opcodes():
        if tag != "equal":
            yield from _token_hunks(before[pa[i1]:pa[i2]], after[pb[j1]:pb[j2]], pa[i1])


def derive_changes(before: str, after: str, annotations=(), default_check: str = "") -> list[Change]:
    """The changes that turn before into after, labelled from annotations
    (each used at most once, matched on exact before/after text, in order)."""
    pool = list(annotations)
    out = []
    for s, e, new in _hunks(before, after):
        c = Change(s, e, before[s:e], new, check=default_check)
        for k, a in enumerate(pool):
            if a.before == c.before and a.after == c.after:
                c.check, c.reason, c.decided_by, c.confidence = a.check, a.reason, a.decided_by, a.confidence
                del pool[k]
                break
        out.append(c)
    return out


def apply_changes(text: str, changes: list[Change]) -> str:
    """Apply a selection: drop changes a selected change supersedes, then
    splice the rest from the end of the text backwards."""
    superseded = {d for c in changes for d in c.depends_on}
    keep = [c for c in changes if c.id not in superseded or not c.id]
    for c in sorted(keep, key=lambda c: (c.start, c.end), reverse=True):
        if text[c.start:c.end] != c.before:
            raise ValueError(f"change {c.id or '?'} at {c.start}: expected {c.before!r}, "
                             f"found {text[c.start:c.end]!r}")
        text = text[:c.start] + c.after + text[c.end:]
    return text


def _overlaps(a: int, b: int, ms: int, me: int) -> bool:
    if ms == me:                      # a deletion in the middle text: touching counts
        return a <= ms <= b
    if a == b:                        # an insertion: strictly inside counts
        return ms < a < me
    return a < me and ms < b


def compose(original: str, middle: str, first: list[Change], second: list[Change]) -> list[Change]:
    """first: changes original -> middle; second: changes middle -> final.
    Returns first plus second re-expressed against original."""
    F = sorted(first, key=lambda c: (c.start, c.end))
    mid, shift = [], 0
    for f in F:
        ms = f.start + shift
        mid.append((ms, ms + len(f.after), f))
        shift += len(f.after) - (f.end - f.start)

    def to_orig(p: int, exclude: set[int] = frozenset()) -> int:
        return p - sum(len(f.after) - (f.end - f.start)
                       for k, (ms, me, f) in enumerate(mid) if me <= p and k not in exclude)

    out = list(first)
    group_s: list[Change] = []
    group_f: set[int] = set()

    def flush():
        if not group_s:
            return
        if not group_f:
            for s in group_s:
                out.append(Change(to_orig(s.start), to_orig(s.end), s.before, s.after, s.check,
                                  s.reason, s.decided_by, s.confidence, s.id, s.pass_))
        else:
            ua = min([s.start for s in group_s] + [mid[k][0] for k in group_f])
            ub = max([s.end for s in group_s] + [mid[k][1] for k in group_f])
            seg = middle[ua:ub]
            for s in sorted(group_s, key=lambda s: (s.start, s.end), reverse=True):
                seg = seg[:s.start - ua] + s.after + seg[s.end - ua:]
            oa, ob = to_orig(ua, group_f), to_orig(ub)
            by = [s.decided_by for s in group_s]
            out.append(Change(oa, ob, original[oa:ob], seg,
                              "+".join(dict.fromkeys(s.check for s in group_s)),
                              "; ".join(r for r in dict.fromkeys(s.reason for s in group_s) if r),
                              "model" if "model" in by else "cache" if "cache" in by else "rule",
                              min(s.confidence for s in group_s), group_s[0].id, group_s[0].pass_,
                              tuple(mid[k][2].id for k in sorted(group_f))))
        group_s.clear()
        group_f.clear()

    # A group is a run of second-pass changes connected through the first-pass
    # changes they overlap; a second-pass change that overlaps none is its own group.
    for s in sorted(second, key=lambda c: (c.start, c.end)):
        hit = {k for k, (ms, me, _f) in enumerate(mid) if _overlaps(s.start, s.end, ms, me)}
        if group_s and not (hit & group_f):
            flush()
        group_s.append(s)
        group_f |= hit
        if not hit:
            flush()
    flush()
    return out
```

```python
def _annotations(applied: list[Edit], decisions: list[Decision]) -> list[Annotation]:
    by_edit = {}
    for d in decisions:
        if d.replacement:
            by_edit.setdefault((d.item.word, d.replacement), d)
    out = []
    for e in applied:
        d = by_edit.get((e.original, e.replacement)) if e.source == "adjudicated" else None
```

```python
"""Settings for one file: built-in defaults < project file < front matter < flags."""

from __future__ import annotations

import functools
import re
import tomllib
from dataclasses import dataclass
from pathlib import Path

import yaml

PASSES = ("style", "proof")
STYLE_TIERS = ("variety", "guide", "ambiguous", "numbers", "serial-comma", "abbreviations", "punctuation")
PROOF_TIERS = ("hygiene", "mechanical", "typos", "adjudicated", "compounds", "commas")
TIERS = STYLE_TIERS + PROOF_TIERS
SETTINGS_FILES = ("prosefix.toml", ".prosefix.toml")
FRONT = re.compile(r"\A---\r?\n(.*?)\r?\n---\r?\n", re.S)

_LISTS = {"only": PASSES, "skip": TIERS, "exclude": None, "accept": None}
_PROJECT_KEYS = ("target", "style", "only", "skip", "exclude", "accept", "accept_file", "cache")
_NOTE_KEYS = ("target", "style", "only", "skip")


class SettingsError(ValueError):
    pass


@dataclass(frozen=True)
class Project:
    root: Path | None
    source: Path | None
    values: dict


@dataclass(frozen=True)
class Settings:
    target: str = "us"
    style: str | None = None
    only: tuple[str, ...] = PASSES
    skip: frozenset[str] = frozenset()
    exclude: tuple[str, ...] = ()
    accept: tuple[str, ...] = ()
    cache: Path | None = None
    project: Path | None = None
    off: bool = False
    note: str | None = None


def _validate(table, where: str, allowed: tuple[str, ...]) -> dict:
    if not isinstance(table, dict):
        raise SettingsError(f"{where}: settings must be a table")
    for k, v in table.items():
        if k not in allowed:
            raise SettingsError(f"{where}: unknown key '{k}' (known: {', '.join(allowed)})")
        if k == "target" and v not in ("us", "uk"):
            raise SettingsError(f"{where}: target must be \"us\" or \"uk\", not {v!r}")
        if k in ("style", "accept_file", "cache") and not isinstance(v, str):
            raise SettingsError(f"{where}: {k} must be a string, not {v!r}")
        if k in _LISTS:
            if not isinstance(v, list) or not all(isinstance(x, str) for x in v):
                raise SettingsError(f"{where}: {k} must be a list of strings, not {v!r}")
            choices = _LISTS[k]
            bad = [x for x in v if choices is not None and x not in choices]
            if bad:
                raise SettingsError(f"{where}: {k} has unknown value '{bad[0]}' "
                                    f"(known: {', '.join(choices)})")
    return dict(table)


def _load_toml(path: Path) -> dict:
    try:
        return tomllib.loads(path.read_text(encoding="utf-8"))
    except (OSError, UnicodeDecodeError, tomllib.TOMLDecodeError) as e:
        raise SettingsError(f"{path}: cannot read settings: {e}") from e


@functools.lru_cache(maxsize=None)
def _project_for_dir(d: Path) -> Project:
    for p in [d, *d.parents]:
        for name in SETTINGS_FILES:
            f = p / name
            if f.is_file():
                return Project(p, f, _validate(_load_toml(f), str(f), _PROJECT_KEYS))
        py = p / "pyproject.toml"
        if py.is_file():
            table = _load_toml(py).get("tool", {}).get("prosefix")
            if table is not None:
                return Project(p, py, _validate(table, f"{py} [tool.prosefix]", _PROJECT_KEYS))
    return Project(None, None, {})


def find_project(path: Path) -> Project:
    d = path if path.is_dir() else path.parent
    return _project_for_dir(d.resolve())


find_project.cache_clear = _project_for_dir.cache_clear       # for tests


def front_matter(text: str) -> tuple[dict | None, str | None]:
    m = FRONT.match(text)
    if not m:
        return None, None
    try:
        data = yaml.safe_load(m.group(1))
    except yaml.YAMLError as e:
        return None, f"front matter does not parse ({type(e).__name__}); project settings used"
    if data is None:
        return {}, None
    if not isinstance(data, dict):
        return None, "front matter is not a mapping; project settings used"
    return data, None


def _read_accept_file(root: Path, name: str) -> list[str]:
    path = root / name
    try:
        lines = path.read_text(encoding="utf-8").splitlines()
    except (OSError, UnicodeDecodeError) as e:
        raise SettingsError(f"{path}: cannot read accept_file: {e}") from e
    return [l.strip() for l in lines if l.strip() and not l.strip().startswith("#")]


def resolve(path: Path | None, text: str, flags: dict, project: Project) -> Settings:
    v: dict = {"target": "us"}
    v.update(project.values)
    fm, note = front_matter(text)
    off = False
    if fm is not None:
        p = fm.get("prosefix")
        where = f"{path or '-'}: front matter 'prosefix'"
        if p is False or p == "off":
            off = True
        elif isinstance(p, dict):
            v.update(_validate(p, where, _NOTE_KEYS))
        elif p is not None:
            raise SettingsError(f"{where} must be off or a mapping, not {p!r}")
        if not (isinstance(p, dict) and "target" in p):
            lang = str(fm.get("lang", "")).strip().lower()
            if lang in ("en-gb", "en-uk"):
                v["target"] = "uk"
            elif lang == "en-us":
                v["target"] = "us"
    v.update({k: val for k, val in flags.items() if val is not None})
    accept = list(v.get("accept", []))
    if project.root and "accept_file" in v:
        accept += _read_accept_file(project.root, v["accept_file"])
    base = project.root or Path.cwd()
    return Settings(target=v["target"], style=v.get("style"),
                    only=tuple(v.get("only", PASSES)), skip=frozenset(v.get("skip", ())),
                    exclude=tuple(v.get("exclude", ())), accept=tuple(accept),
                    cache=base / v.get("cache", ".prosefix/cache.json"),
                    project=project.source, off=off, note=note)
```

```python
"""One file through stylefix then proofix, with changes against the original."""

from __future__ import annotations

import threading
from dataclasses import dataclass, field
from pathlib import Path

from adjudicate import Cache, Change, ReviewItem, Skipped, compose
from proofix import api as proof
from proofix.commas import CommaCache
from stylefix import api as style
from stylefix.cli import BUILTIN_ACCEPT

from .settings import FRONT, PROOF_TIERS, STYLE_TIERS, Settings


class SharedCache(Cache):
    def save(self):            # adjudicate() calls this after every batch; we write once, at the end
        pass

    def flush(self):
        Cache.save(self)


class SharedCommaCache(CommaCache):
    def save(self):
        pass

    def flush(self):
        CommaCache.save(self)


@dataclass
class Caches:
    cache: Cache
    commas: CommaCache

    def flush(self):
        for c in (self.cache, self.commas):
            if hasattr(c, "flush"):
                c.flush()


_LOCK = threading.Lock()
_OPEN: dict[Path, Caches] = {}


def caches_for(settings: Settings, mode: str) -> Caches:
    """mode: use (read and write), replay (read; written only if new answers arrive), off (none)."""
    if mode == "off" or settings.cache is None:
        return Caches(Cache(None), CommaCache(None))
    with _LOCK:
        if settings.cache not in _OPEN:
            _OPEN[settings.cache] = Caches(SharedCache(settings.cache),
                                           SharedCommaCache(settings.cache.with_name("commas.json")))
        return _OPEN[settings.cache]


def flush_all() -> None:
    with _LOCK:
        for c in _OPEN.values():
            c.flush()
        _OPEN.clear()


def user_accept() -> tuple[list[str], set[str]]:
    words: list[str] = []
    cfg = Path.home() / ".config"
    import os
    cfg = Path(os.environ.get("XDG_CONFIG_HOME") or cfg)
    for p in (BUILTIN_ACCEPT, cfg / "stylefix" / "accept.txt", cfg / "proofix" / "accept.txt"):
        if p.exists():
            words += [l.strip() for l in p.read_text(encoding="utf-8").splitlines()
                      if l.strip() and not l.strip().startswith("#")]
    return words, {w.lower() for w in words}


@dataclass
class FileResult:
    path: str
    status: str                       # changed | unchanged | skipped | error
    reason: str | None
    settings: Settings
    original: str
    output: str
    changes: list[Change] = field(default_factory=list)
    review: list[ReviewItem] = field(default_factory=list)
    skipped: list[Skipped] = field(default_factory=list)


def _line(text: str, pos: int) -> int:
    return text.count("\n", 0, pos) + 1


def process(label: str, text: str, settings: Settings, endpoint, caches: Caches,
            replay: bool, parallel: int = 4) -> FileResult:
    if settings.off:
        return FileResult(label, "skipped", "prosefix: off", settings, text, text)
    m = FRONT.match(text)
    head = m.group(0) if m else ""
    body = text[len(head):]
    style_accept, proof_accept = user_accept()
    style_accept += list(settings.accept)
    proof_accept |= {w.lower() for w in settings.accept}
    review: list[ReviewItem] = []
    skipped: list[Skipped] = []
    if settings.note:
        review.append(ReviewItem(1, "note", settings.note, "settings", "prosefix"))
    middle, first = body, []
    if "style" in settings.only:
        r = style.fix(body, style.Options(target=settings.target, style=settings.style,
                                          accept=style_accept, parallel=parallel,
                                          skip=settings.skip & frozenset(STYLE_TIERS),
                                          require_vale=False, replay_cache=replay),
                      endpoint, caches.cache)
        middle, first, review, skipped = r.text, r.changes, review + r.review, skipped + r.skipped
    final, second = middle, []
    if "proof" in settings.only:
        r2 = proof.fix(middle, proof.Options(target=settings.target, accept=frozenset(proof_accept),
                                             style=settings.style or "none", parallel=parallel,
                                             skip=settings.skip & frozenset(PROOF_TIERS),
                                             replay_cache=replay),
                       endpoint, caches.cache, caches.commas)
        final, second = r2.text, r2.changes
        review += r2.review
        skipped += r2.skipped
    for n, c in enumerate(first, 1):
        c.id = f"s{n}"
    for n, c in enumerate(second, 1):
        c.id = f"p{n}"
    changes = compose(body, middle, first, second)
    shift = len(head)
    for c in changes:
        c.start += shift
        c.end += shift
    head_lines = head.count("\n")
    review = [ReviewItem(i.line + head_lines, i.kind, i.message, i.check, i.pass_) for i in review]
    output = head + final
    return FileResult(label, "changed" if output != text else "unchanged", None, settings,
                      text, output, changes, review, skipped)
```

```python
"""The versioned JSON document (schema 1)."""

from __future__ import annotations

from . import __version__


def utf16_offsets(text: str) -> list[int]:
    """m[i] = UTF-16 code units before code point i (len(text)+1 entries)."""
    out = [0]
    for ch in text:
        out.append(out[-1] + (2 if ord(ch) > 0xFFFF else 1))
    return out


def file_entry(r) -> dict:
    s = r.settings
    entry = {"path": r.path, "status": r.status, "reason": r.reason,
             "settings": {"target": s.target, "style": s.style, "only": list(s.only),
                          "skip": sorted(s.skip)}}
    if r.status == "error":
        return entry
    m = utf16_offsets(r.original)
    entry["changes"] = [{"id": c.id, "pass": c.pass_, "check": c.check,
                         "start": m[c.start], "end": m[c.end],
                         "line": r.original.count("\n", 0, c.start) + 1,
                         "before": c.before, "after": c.after, "reason": c.reason,
                         "decided_by": c.decided_by, "confidence": round(c.confidence, 3),
                         "depends_on": list(c.depends_on)} for c in r.changes]
    entry["review"] = [{"pass": i.pass_, "line": i.line, "kind": i.kind, "check": i.check,
                        "message": i.message} for i in r.review]
    entry["output"] = r.output
    return entry


def document(results, endpoint, skipped) -> dict:
    ep = None if endpoint is None else {"url": endpoint.url, "model": endpoint.model,
                                        "source": endpoint.sources.get("url", "")}
    return {"schema": 1, "prosefix": __version__, "endpoint": ep,
            "skipped": [{"what": s.what, "why": s.why, "fix": s.fix} for s in skipped],
            "files": [file_entry(r) for r in results]}
```

Then the rest of `cli.py` — write it to these rules (each rule is tested in Step 1 or named here):

1. `--setup` → `run_setup("prosefix")`; `--check-endpoint` → `check_endpoint("prosefix", preset="none" if llm in ("none", "cached") else llm, url, model, timeout)`; `--doctor` → print, for each of vale, languagetool, typos: `found  <path>` or `missing  <install_hint>`; then the `check_endpoint` rows (call it with `out=sys.stdout`); then `settings: <path of the project file for the cwd, or "none (defaults)">`; exit 0.
2. No paths and no mode flag → `parser.error("give files, directories, or - for stdin")`. `-o` with more than one input, or with a directory → `parser.error`. `--strict` without `--check` → `parser.error`.
3. `--skip` is split on commas; unknown names → `parser.error` naming them. Flags dict for `resolve`: `{"target": args.target, "style": args.style, "only": (args.only,) if args.only else None, "skip": skip_list or None}`.
4. Endpoint: `none`/`cached` → `ep = None`; else `resolve_endpoint("prosefix", args.llm, url=…, model=…, timeout=…)`, `ConfigError` → stderr `prosefix: <e>`, exit 2. Cache mode: `--no-cache` or `none` → `"off"`; `cached` → `"replay"`; else `"use"`. `replay = args.llm == "cached"`.
5. `--require`: parse names; `tools.detect()`; any requested tool missing (or `model` requested and `ep is None`) → stderr `prosefix: required <name> is missing (<hint>)`, exit 2.
6. Inputs: `-` → one job with text from stdin, label `str(args.stdin_filename)` if given else `"-"`, settings looked up from `args.stdin_filename` or `Path.cwd() / "stdin.md"`. A file → one job. A directory → walk with `Path.rglob("*")`, keeping files whose suffix is in `EXTS`, skipping any path with a part in `SKIP_DIRS` or starting with `.`, and any path matching the project's `exclude` globs (relative to the project root, `fnmatch` with `**` matching across `/` — use `PurePath.full_match` on 3.13+, else `fnmatch.fnmatch` on the posix relative path). Explicitly named files are processed even if excluded. Non-existent path → stderr `prosefix: no such file: <p>`, exit 2 at the end, other files still processed.
7. Per job: read text (UTF-8; decode error → file status `error` with reason); `project = find_project(...)`; `settings = resolve(...)` (`SettingsError` → stderr `prosefix: <e>`, the job is an `error`, run exits 2); `caches = engine.caches_for(settings, mode)`; `engine.process(...)`. Run jobs in `ThreadPoolExecutor(max_workers=args.jobs)`, results in input order. After all jobs, `engine.flush_all()` unless mode is `"off"`.
8. Skipped capabilities: collect every result's `skipped`, deduplicate by `what`; add `Skipped("model decisions and comma placement", "no model endpoint", "prosefix --setup")` when `ep is None` and `args.llm != "none"` (with `cached`: why = "--llm cached: cached decisions only"). Unless `--quiet` or `--json`, print each once: `prosefix: skipped <what> (<why>: <fix>)`.
9. Output by mode:
   - default: for each changed file write `output` (to `-o` if given; stdout for stdin), then unless `--quiet` print `prosefix: <path>: <n> change(s), <k> for review` per file and a total line.
   - `--diff`: `difflib.unified_diff(original, output, path, path)` to stdout for each changed file.
   - `--check`: print `would change <path>` per changed file (and per file with review items if `--strict`), then `would change N file(s)` / `nothing to change`; exit 1 if any.
   - `--json`: `json.dump(jsonout.document(results, ep, skipped), sys.stdout, ensure_ascii=False, indent=1)`.
   - `--changes`: for each change print `<path>:<line>: <before!r> -> <after!r>  [<pass> <check>, <decided_by><, reason>]` to stderr.
   - `--report FILE`: a Markdown file with one `## <path>` section per file listing changes (same line format) and review items.
10. Exit: 2 if any usage/settings/input error occurred; else 1 if `--check` found changes (or review items with `--strict`); else 0.
